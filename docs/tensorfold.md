# TensorFold

TensorFold (https://github.com/ashhart/TensorFold) is an inference engine that runs on **CUDA**
(NVIDIA GPUs) and **Metal** (Apple Silicon) platforms.

This knowledge-base entry is a stub: ai-bootstrap does not yet ship verified install or serving
instructions for it. When the user wants to use TensorFold:

1. Read the project's README and docs at the URL above (fetch them, or ask the user to paste the
   relevant parts) instead of guessing commands or flags.
2. Check the platform fits: an NVIDIA GPU with a working driver (`nvidia-smi`) or an Apple Silicon
   Mac. It does not apply to AMD, Intel or CPU-only machines.
3. Save what you learn (install steps, how to serve an OpenAI-compatible endpoint, ports, gotchas)
   to a `tensorfold` memory file so the next session has it.
